# Python Weather App

A simple desktop weather application built with Python and PySide6 that uses the OpenWeather API to fetch real-time weather information.

## Features

- Search weather by city
- Display current temperature
- Display humidity
- Display weather conditions
- Fetch real-time weather data
- Simple desktop graphical user interface

## Technologies Used

- Python
- PySide6
- Requests
- OpenWeather API
- JSON
- python-dotenv

## Setup

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Create a `.env` file in the project directory.

Add your OpenWeather API key to the `.env` file:

```env
API_KEY=your_api_key_here
```

5. Run the application:

```bash
python weather.py
```

> Keep your `.env` file private and never upload your API key to GitHub.
